Início / rclone-gdrive

Vários Google Drives, como pastas num servidor só

Aplicativo de uso pessoal que monta os Google Drives do próprio dono como pastas em um servidor próprio, usando o rclone.

O que é

Quem tem mais de uma conta Google acaba com arquivos espalhados em vários Drives. O rclone-gdrive junta esses Drives num só lugar: cada conta aparece como uma pasta no servidor próprio, e os arquivos são abertos como quaisquer outros.

Usa a API do Google Drive só para que o próprio dono acesse os arquivos das contas que ele mesmo autoriza.

Como funciona

  1. O dono autoriza cada conta

    Cada conta Google é autorizada uma vez, pela tela de permissão do próprio Google.

  2. O rclone monta o Drive como pasta

    Os arquivos e pastas da conta aparecem no servidor próprio como uma pasta comum.

  3. Tudo fica no servidor do dono

    Os tokens de acesso e um cache temporário dos arquivos ficam só nesse servidor. Nada vai para terceiros.

Situação

Uso pessoal; não é oferecido ao público. Não há análise, venda nem uso dos dados para publicidade. Detalhes na política de privacidade.

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
