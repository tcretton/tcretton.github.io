Início / Scripts de infraestrutura Linux

Servidores cuidados com o mesmo padrão

Scripts de código aberto para servidores domésticos, VPS e ambientes de clientes, reunidos num painel central.

O que resolve

Cada servidor acaba com seus próprios scripts de backup e manutenção, escritos às pressas e diferentes entre si. Quando algo dá errado, ninguém lembra como restaurar.

Um conjunto único, testado e documentado deixa todas as máquinas no mesmo padrão.

Como funciona

  1. Instala com um comando

    Os scripts vão para a pasta do usuário e ganham um atalho para o painel.

  2. Usa pelo painel

    Um menu central abre backup, monitoramento, provisionamento e manutenção sem decorar comandos.

  3. Atualiza com um comando

    Puxa a versão nova do repositório e reinstala, mantendo os agendamentos que já existem.

O que faz

  • Backup com restauração testada

    Backup por perfis, restauração guiada e simulado de restauração para provar que funciona.

  • Backup fora do servidor

    Envio da cópia para a nuvem, com passo a passo documentado.

  • Monitoramento

    Checagem de saúde, varredura da rede e status de todas as máquinas.

  • Provisionamento

    Preparação de máquina nova e inventário do que está instalado.

  • Manutenção

    Atualização do sistema, limpeza e conferência dos agendamentos.

  • Testes automatizados

    As funções compartilhadas têm testes e cada mudança passa por revisão.
