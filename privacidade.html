Política de privacidade — rclone-gdrive

Atualizada em 16 de outubro de 2026.

O rclone-gdrive é um aplicativo de uso pessoal de Tércio Cretton. Ele usa a API do Google Drive apenas para que o próprio dono acesse os arquivos das suas contas Google em um servidor doméstico.

  • Dados acessados: arquivos e pastas do Google Drive das contas que o próprio usuário autoriza.
  • Uso: os arquivos são exibidos como pastas no servidor do dono. Não há análise, venda ou uso para publicidade.
  • Compartilhamento: nenhum dado é enviado a terceiros.
  • Armazenamento: os tokens de acesso e um cache temporário dos arquivos ficam apenas no servidor do dono.
  • Revogação: o acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
